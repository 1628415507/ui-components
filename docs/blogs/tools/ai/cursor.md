# Cursor

## Cursor 自动读取规则配置教程

在 Cursor 中，如果希望 AI 在回答问题时始终自动读取特定的规则文件（如 `myRule.md`），而不需要每次手动 `@`，可以使用以下几种方案：

### 方案一：使用 `.cursor/rules` 规则文件（推荐）

这是 Cursor 目前最强大且官方推荐的方案，支持精准的触发条件。

1. **创建目录**：在项目根目录下创建 `.cursor/rules` 文件夹。
2. **创建规则文件**：创建一个以 `.mdc` 结尾的文件，例如 `global-rules.mdc`。
3. **配置自动触发**：在文件顶部添加 Frontmatter 元数据，设置 `globs: **/*` 使其对所有文件生效。

**示例文件内容：**

```markdown
---
description: 始终应用的全局业务与开发规范
globs: **/*
---

## 规则内容
这里粘贴你的规则具体内容...
```

---

### 方案二：使用项目级 `.cursorrules` 文件

这是较早期的传统方式，简单直接。

1. 在项目根目录下创建一个名为 `.cursorrules` 的文件（注意没有后缀名）。
2. 将你的规则内容直接粘贴进去。
3. Cursor 的 Agent（Chat 和 Composer）在对话时会自动加载该文件作为上下文。

---

### 方案三：在 IDE 全局设置中配置

如果你希望规则在所有打开的项目中都生效：

1. 打开 Cursor 设置：`Ctrl + Shift + J` (或点击右上角齿轮 -> `General`)。
2. 找到 **"Rules for AI"** 输入框。
3. 将规则内容粘贴进去。

---

### 架构师建议

* **优先选方案一**：`.mdc` 文件允许根据文件路径（`globs`）区分规则，性能更好且逻辑更清晰。
* **规则维护**：建议将通用规范放在 `.cursor/rules/` 下，便于团队共享和版本管理。

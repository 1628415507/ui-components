# Windows 远程桌面配置指南（IP 连接与密码设置）

## 1. 概述

通过 IP 远程控制另一台 Windows 电脑，使用系统自带的**远程桌面（RDP）**，默认端口为 **3389**。

前提是**两台机器网络可达**，且**被控端已开启远程服务**。

---

## 2. 前提条件

1. **网络可达**
   - 同一局域网：直接使用内网 IP（如 `192.168.1.100`）
   - 跨公网：需要公网 IP，或在路由器上做**端口转发**
2. **被控电脑已开启远程桌面**（仅知道 IP 不够）
3. **防火墙放行 3389 端口**

---

## 3. 配置与连接步骤

适合两台都是 Windows，或从 Windows 连接 Windows 的场景。

### 3.1 在被控电脑（B 电脑）上配置

1. 打开 **设置 → 系统 → 远程桌面 → 开启「远程桌面」**
2. 查看本机 IP：`Win + R` → 输入 `cmd` → 执行：

```powershell
ipconfig
```

查看 **IPv4 地址**（如 `192.168.1.105`）。

3. 确认登录账号已设置密码（RDP 必须使用账户密码，PIN 不能代替）

### 3.2 在控制端（A 电脑）上连接

1. `Win + R` → 输入 `mstsc` → 回车
2. 在「计算机」中填写 B 电脑的 IP，例如：`192.168.1.105`
3. 输入 B 电脑的用户名和密码

### 3.3 端口与防火墙

- 默认端口：**3389**
- 若连接失败，在被控电脑上检查：**Windows 防火墙 → 允许「远程桌面」通过防火墙**

### 3.4 跨公网连接（不在同一 WiFi）

1. 在被控端路由器做**端口转发**：外网 3389 → B 的内网 IP:3389
2. 使用 B 的**公网 IP** 连接（可在 B 上搜索「我的 IP」查看）
3. **安全提示**：公网暴露 3389 风险较高，建议修改默认端口或使用 VPN

---

## 4. 被控电脑没有远程密码怎么配置

Windows 远程桌面（RDP）**要求被控账号必须设置密码**才能远程登录。

#### 步骤 1：设置登录密码

在被控电脑上：

1. **设置 → 账户 → 登录选项**
2. 找到 **密码** → 点击 **添加** 或 **更改**
3. 设置一个密码（**PIN 不能代替 RDP 密码**）

#### 步骤 2：开启远程桌面

**设置 → 系统 → 远程桌面 → 开启**

#### 步骤 3：确认账号有远程权限

- **家庭版** Windows 只能**被远程连接**，不能主动用 `mstsc` 连接别人
- **专业版 / 企业版** 可主动连接其他电脑
- 被控账号最好在「远程桌面用户」列表中（系统一般会自动添加当前用户）

#### 步骤 4：从另一台电脑连接

`Win + R` → `mstsc` → 输入被控电脑 IP → 使用 **用户名 + 密码** 登录

---

## 5. 常见问题排查

| 现象 | 可能原因 |
|------|----------|
| 连不上 | IP 写错、不在同一网段、远程桌面未开启 |
| 连接超时 | 防火墙拦截、路由器未做端口转发 |
| 有 IP 但拒绝连接 | 未开启远程桌面，或账号无权限 |
| 公网连不上 | 运营商无公网 IP（大内网 / CGNAT），需内网穿透 |
| 设置了 PIN 仍连不上 | PIN 仅用于本机解锁，RDP 需使用 **Windows 账户密码** |
| 使用 Microsoft 账户登录 | 远程时使用 **Microsoft 账户邮箱 + 微软账户密码**，不是 PIN |

---

## 6. 快速操作清单

1. 被控端：**设置 → 系统 → 远程桌面 → 开启**
2. 被控端：给登录账号**设置密码**
3. 被控端：`ipconfig` 查看 **IPv4 地址**
4. 控制端：`Win + R` → `mstsc` → 输入 IP → 登录
